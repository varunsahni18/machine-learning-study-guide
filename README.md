# Machine Learning Study Guide

An independent study companion for Chapters 1–6 of [*Machine Learning: a Lecture Note* by Kyunghyun Cho](https://arxiv.org/html/2505.03861v1). It includes 380 explanations, 53 worked problems, and 15 interactive figures.

The public edition links to the author's chapter and section anchors. Mathematics and interactive figures are embedded in the standalone HTML.
