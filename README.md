# Machine Learning Study Guide

A study companion for Chapters 1–6 of Kyunghyun Cho’s *Machine Learning: a Lecture Note*, based on the September 22, 2026 course PDF. It includes 380 lessons, 53 worked problems, and 15 interactive figures.

Search for a printed page such as `p. 88` or a PDF viewer page such as `viewer page 92` to jump to matching lessons. To view an original passage, choose **Open course PDF** and select your copy of `Machine_Learning__a_Lecture_Note (4).pdf`. The course PDF stays in your browser tab.
