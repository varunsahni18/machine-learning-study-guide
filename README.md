# Machine Learning Study Guide

A study companion for Chapters 1–6 of Kyunghyun Cho’s *Machine Learning: a Lecture Note*, based on the September 22, 2026 course edition. All 380 lessons display their source passages, equations, and explanations inline. The guide includes 44 section explanations, 53 worked problems, and 15 interactive figures.

Search for a printed page such as `p. 88` or a PDF viewer page such as `viewer page 92` to find matching lessons. Use the section pages for each topic's explanation and prerequisites.
